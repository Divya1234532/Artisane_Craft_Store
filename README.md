# Artisané ✨

An aesthetic handmade craft shopping website built using HTML, CSS, and JavaScript.

## 🌸 About the Project

Artisané is a beautifully designed craft store web app where customers can explore and purchase handmade crafts online.  
The website focuses on a clean aesthetic UI with a soft and elegant shopping experience.

## 🚀 Features

- 🛍️ Handmade craft showcase
- 💖 Aesthetic and responsive UI
- 📱 Mobile-friendly design
- 🖼️ Product cards with images and prices
- 💬 Buy through WhatsApp
- ✨ Smooth hover animations

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages
